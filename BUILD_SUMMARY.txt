TROUBLESHOOTING

"Cannot find UE4Editor":
  → Verify Engine/Binaries/Linux/UE4Editor exists
  → Check engine is compiled: ./GenerateProjectFiles.sh

APK Installation Fails:
  → Ensure device API ≥ 21: adb shell getprop ro.build.version.sdk
  → Try: adb install -r -g Binaries/Android/Fallout5.apk

Build Runs Out of Memory:
  → Reduce parallel jobs: make -j2 (instead of -j4)
  → Increase swap space if on low-end system
